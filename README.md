# Jakarta Metro Public CCTV Player\n\nA React + Vite dashboard for browsing public CCTV/video sources around Jakarta, Tangerang, Tangerang Selatan, Depok, and Bekasi.\n\n## Audit status\n\n- Repository: public, TypeScript, default branch `main`.\n- Current access: repository owner has admin, maintain, push, pull, triage, and write access.\n- Branch protection: not enabled on the inspected branches.\n- Security: secret scanning and push protection are enabled; Dependabot security updates are disabled.\n- Frontend: React 19 + Vite 6.\n- Data model: static camera catalog with YouTube embed IDs, region/category filters, favorites in `localStorage`, URL camera selection, keyboard navigation, and an optional Gemini traffic assistant.\n\n## Functional scope\n\nThe player uses public embed sources only. It does not bypass camera authentication, scrape private RTSP feeds, or expose credentials. A stream is considered playable only when its provider allows embedding and the source remains publicly available.\n\nBefore production use, each camera entry should be checked periodically for HTTP/embed availability and replaced when the public source changes.\n\n## Local development\n\n```bash\nnpm install\nnpm run dev\n```\n\nFor the optional Gemini assistant, define `GEMINI_API_KEY` in `.env.local`. Do not commit that key.\n\n## Build\n\n```bash\nnpm run build\n```\n
